# Contributing to Forensic Signature AI

Thank you for contributing to **Forensic Signature AI**.

## Local Setup

```bash
git clone https://github.com/subki72/forensic-signature-ai.git
cd forensic-signature-ai
make install
```

## Verification Gates

```bash
make lint
make test
```

## Pre-Commit Hooks

```bash
pip install pre-commit
pre-commit install
```
